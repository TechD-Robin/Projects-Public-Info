

##### 訂閱或者購買

本應用程式的一些功能需要訂閱或非消耗型應用內購買才能解鎖和使用。

本應用程式將使用 App Store 的支付系統，所有費用將通過您的 Apple ID 帳戶進行處理。如果您選擇訂閱服務，訂閱詳情將在您確認訂閱後顯示於您的 Apple ID 帳戶中。請注意，系統會在每個計費週期結束時自動續訂您的訂閱。如果您希望取消訂閱，請務必在當前訂閱週期結束前至少 24 小時進行取消。

若您希望管理或取消訂閱，可以隨時在 App Store 的帳戶設定中進行操作。

取消訂閱的具體步驟如下：
1. 打開您設備上的「設定」應用程式。
2. 點擊螢幕頂部的 Apple ID。
3. 選擇「訂閱項目」。
4. 選擇您希望取消的訂閱。
5. 點擊「取消訂閱」。

您可以隨時在 App Store 的帳戶設置中管理或取消您的訂閱。

退款應通過 Apple 的官方流程處理，通過您的 Apple ID 帳戶申請。開發者僅能根據 App Store 的規定協助退款。
